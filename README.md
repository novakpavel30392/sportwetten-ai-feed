# Sportwetten AI – Public Feed

Dieses Repository enthält ausschließlich den maschinenlesbaren Datenfeed für die Sportwetten-AI-Android-App.

- `latest.json`: aktuell veröffentlichter Spiel- und Analysefeed
- keine Zugangsdaten
- kein privater Modell- oder App-Quellcode

Der Feed dient der technischen Bereitstellung von Modellanalysen und stellt keine Gewinnzusage oder Aufforderung zum Glücksspiel dar.
